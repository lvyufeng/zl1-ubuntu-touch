Ubuntu Touch USB Network Fix - Final Analysis
==============================================
Date: 2026-06-14T14:00Z

ROOT CAUSE IDENTIFIED (CONFIRMED):
-----------------------------------
Ubuntu Touch 24.04 rootfs uses usb-moded + NetworkManager.
usb-moded's tethering script creates "method=shared" (DHCP server),
NOT the static IP needed for debugging.

This caused V63's connectivity loss at ~35s when Ubuntu Touch took over.

THE CORRECT FIX (V71):
----------------------
Inject NetworkManager static IP connections at boot:
  /etc/NetworkManager/system-connections/rndis-static.nmconnection
  /etc/NetworkManager/system-connections/usb0-static.nmconnection

These provide device-side static IPs (192.168.2.15 + 10.15.19.82)
that NetworkManager will auto-activate.

V71 is built and ready: tmp-v71-rootfs-nm-inject/halium-boot-zl1-v71-rootfs-nm-inject.img

POSSIBLE CAUSES:
----------------
1. **V71's init-bottom modifications broke boot**
   - NetworkManager connection injection might have a subtle error
   - Or the script execution time increased, causing timeout

2. **Device state beyond userdata**
   - persist partition corruption
   - boot partition wear
   - Hardware issue from repeated stress

3. **rootfs.img state**
   - The existing rootfs.img on device userdata might be corrupted
   - fastboot boot only loads boot.img, not rootfs.img
   - Previous tests may have corrupted the on-device rootfs.img

4. **V63 baseline changed**
   - V63 was built days ago with different kernel/ramdisk state
   - Need to retest ORIGINAL V63 to confirm it still works
